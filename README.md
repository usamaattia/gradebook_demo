# gradebook_demo

A tiny C# gradebook web app built live in class with AI prompts:
Blazor + SQLite + xUnit, deployed for free on Render.

- **Class script:** [PROMPTS.md](PROMPTS.md) has the setup, every prompt, the checks and the deployment steps.
- **Run it:** `dotnet run --project Gradebook` (needs the .NET 10 SDK)
- **Test it:** `dotnet test`
- **Checkpoints:** the tags `step-0` to `step-5` hold the project after each prompt.
